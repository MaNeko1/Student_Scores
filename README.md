# Student Score to Excel – Python Mini Project

This is a simple Python script that helps you collect student names and scores, calculate their grades, and export the results to an Excel file using `openpyxl`.

## Features

- Input student names and scores via terminal
- Auto grade calculation based on score range
- Export results to `student_results.xlsx`
- Beginner-friendly and easy to customize

## Requirements

- Python 3.x
- openpyxl

Install openpyxl:
```bash
pip install openpyxl
```

## How to Use
1. Clone the repository or download the script.
2. Run the script:
```bash
python student_score_to_excel.py
```
3. Enter the number of students and fill in their names and scores.
4. The Excel file will be saved as student_results.xlsx.
